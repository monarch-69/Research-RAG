# Workflow
1. Listening for Commands: The voice assistant continuously listens for user input and extracts the command.
2. Executing Actions:
2.1. Opening and Closing Applications: Users can say commands like ”Open Notepad” or ”Close Notepad”, and the assistant will handle the task accordingly.
3. Sending Emails:
3.1. The user provides the recipient’s email, subject, and body.
3.2. The assistant composes and sends the email.
4. Browsing the Internet:
4.1. The user says, ”I want information about [topic]”
4.2. The assistant asks whether to perform a web search or check Wikipedia.

# Methodology
1. System Architecture: Our voice assistant system comprises the following components
1.1. Speech Recognition Module: Converts user speech into text.
1.2. Natural Language Processing (NLP): Understands and processes user commands.
1.3. Command Execution Engine: Interprets commands and interacts with the operating system.
1.4. Text-to-Speech (TTS) Module: Provides verbal responses to user queries.
1.5. Web Navigation Module: Uses AI to scroll and read website content aloud.
1.6. Email & Messaging Module: Enables users to send and read emails and compose WhatsApp messages through voice commands.
2. Technologies Used: The system is built using the following technologies
2.1. Python: Core programming language.
2.2. SpeechRecognition & Google Text-to-Speech (gTTS): Forhandling speech input and output.
2.3. NLTK & OpenAI GPT: For processing natural language commands.
2.4. PyAutoGUI & OS Libraries: For automating desktop actions, including opening and closing applications.
2.5. BeautifulSoup & Selenium: For extracting and reading website content.
2.6. Smtplib & Imaplib: For sending and reading emails.
2.7. Pywhatkit: For sending WhatsApp messages.
